## Identify every document that is not in English

ICA requires an official translation when a supporting document is not in English. Review the whole application set, including civil-status records, education certificates, transcripts and business documents.

A document can contain English headings while the important entries remain in another language. Check the names, dates, stamps, annotations and reverse side of each page before deciding that no translation is needed.

## Use a translation route accepted by ICA

ICA's PR document checklist describes the translation arrangements it accepts. These include translations provided by the embassy of the country that issued the document, a notary public in Singapore or the issuing country, and private translations that have been properly attested or notarised in the manner ICA specifies.

Check the current checklist before commissioning the work. Ask the translator or notary what will be supplied and make sure the completed set contains the required certification, attestation or notarisation.

## Keep the source document with the translation

Organise the original-language record and its English translation as a pair. Use clear filenames so the relationship remains obvious after upload, for example `marriage-certificate-original.pdf` and `marriage-certificate-translation.pdf`.

Do not upload only a typed English summary unless ICA's instructions expressly allow it. The translation helps ICA read the source record; it does not replace the underlying document.

## Check names and transliterations

Names written in different alphabets can appear in more than one English spelling. Compare the translation against the passport and the application form. If a certificate uses a different transliteration, keep the original spelling visible and explain the difference accurately where appropriate.

The same check applies to places, institutions and dates. A translator should translate the record as issued. Do not ask for a historical document to be rewritten so that it appears identical to a newer record.

## Allow time for certification

Translation, attestation and notarisation may require several steps. Start with documents that affect eligibility, identity, family relationships, education or employment. This leaves time to resolve missing pages or certification questions before the intended submission date.

If ICA asks for an additional document later, apply the same translation requirements rather than sending an informal explanation in place of the requested record.

## Review the completed upload set

Check that every page is readable and correctly oriented. Confirm that stamps, seals and certification pages are included. Match each translation to the correct source document and remove accidental duplicates.

This preparation does not change how ICA assesses the application. It reduces the risk of submitting a record that cannot be read or verified from the uploaded files.
